
  # FleziBCG

  This is a code bundle for FleziBCG. The original project is available at https://www.figma.com/design/xgdpVOcgkFVjZG30tiNvwb/FleziBCG.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Running E2E tests (Playwright)

  In Ubuntu dev containers, install browser and OS dependencies once before running Playwright:

  `npx playwright install chromium`

  `npx playwright install-deps chromium`

  Run the suite with:

  `npx playwright test`
