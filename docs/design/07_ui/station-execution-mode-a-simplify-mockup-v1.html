Rules applied
D-04 · IR-05 Single error banner at top of page. NO inline error block in OpenSessionPanel, NO toast.error. Failure → exactly 1 banner.
IR-05 Banner uses role="alert"; severity="warning" (amber/yellow). For severity="danger", use red palette.
Banner content: 3-line stack — title (font-semibold), message (regular), recovery (smaller, opacity reduced).
Anti-pattern check: if a toast appears here ALONGSIDE the banner, IR-05 violated. Same applies to UNKNOWN errors.
Mapping for 7 known codes: see stationCommandErrorMessages.ts ERROR_MAP. UNKNOWN fallback uses FALLBACK_ERROR template, also via banner only.
Banner position: immediately below page header, above row-card. Persistent until commandError cleared by next successful action.
