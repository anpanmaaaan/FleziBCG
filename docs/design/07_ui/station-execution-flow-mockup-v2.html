Station Execution Flow Mockup v2

Phiên bản này fix các blocker đã review trên mockup v1: Mode A đổi sang 3-row single card không Shell, bỏ wizard 5-step, thêm empty-state và error-banner, tách Operator/QA cho Quality Hold, bỏ "Pass preview" trong Quality Measurement, thêm close-confirm dialog cho End Session.

Backend là source of truthAction visibility, hold state, closure, allowed_actions đều backend-derived. FE không tự tính.
One primary action per modeMỗi screen state chỉ có 1 primary CTA. Secondary actions không cạnh tranh visual.
Token-compliant hit areaPrimary CTA 56px, secondary 48px, gap ≥ 12px, KPI value ≥ 48px.
Color + icon + textState không bao giờ chỉ dùng màu. Pill có dot + label. Operator color-blind vẫn đọc được.

Implementation Notes For Coding Agent

Scope intent: Visual direction pack, không phải production code. Translate sang component hiện có (StationWorkflowShell, OpenSessionPanel, IdentifyOperatorPanel, BindEquipmentPanel, CloseSessionPanel cho Mode A; ExecutionStateHero, AllowedActionZone, QuantitySummaryPanel cho Mode B).

Hard requirements:

  • Mode A KHÔNG dùng StationWorkflowShell; KHÔNG dùng StationEntryPanel; KHÔNG wizard 5-step (D-01..D-02).
  • Mode A có exact 1 primary CTA top-level "Enter queue"; helper text reflect missing prerequisite (D-05, IR-06). Variable name: canNavigateToQueueByVisibleSetupState.
  • Error display: TOP banner duy nhất, no toast on failure cho command-guard codes (D-04, IR-05).
  • Empty state khi !stationId: 1 amber notice, không Shell, không rows (D-08).
  • Close-session confirm dialog OWN bởi CloseSessionPanel (IR-01).
  • Cockpit (Mode B): action visibility từ allowed_actions; KHÔNG STX label, KHÔNG generic partial banner.
  • Quality Measurement: KHÔNG render "Pass preview" / "No hold will be opened". Sau submit, backend trả quality_result.
  • Quality Hold: tách Operator view và QA view (route/authorization khác nhau), KHÔNG render side-by-side.
  • Touch targets: primary 56px, secondary 48px, gap ≥ 12px, KPI value ≥ 48px.
  • Pill states: dot + label (color + text), không chỉ color.
  • Focus-visible ring trên mọi interactive element.
  • aria-hidden="true" trên decorative symbols (●, ○, dot, step number).

Suggested slice ordering:

  1. FE-SE-MODEA-SIMPLIFY-09 — Setup 3-row card + empty + error + close-confirm dialog ownership.
  2. FE-SE-COCKPIT-REWORK-07 — Cockpit Mode B hero + allowed_actions + interrupted mode (paused, downtime).
  3. FE-SE-QUALITY-MEASURE-XX — Quality entry spec-reference panel; remove pass preview.
  4. FE-SE-QUALITY-HOLD-XX — Operator hold view + QA disposition route (separate).
  5. FE-SE-SUPERVISOR-TIMELINE-XX — Supervisor timeline read-only.

Caveats: Reason list, disposition list, spec ranges đều backend-derived master data — không hardcode trong FE.
