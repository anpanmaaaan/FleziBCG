# DESIGN.md Format Rules

DESIGN.md should include: Visual Theme, Color Palette, Typography, Component Stylings, Layout Principles, Depth & Elevation, Do's and Don'ts, Responsive Behavior, Agent Prompt Guide, FleziBCG-Specific UI Contracts, Review Checklist.

Rules: concrete instructions, semantic tokens with usage, component behavior, responsive behavior, do-not-fake rules, operator/shopfloor constraints. Do not copy third-party brand. Do not let DESIGN.md override domain contracts.
